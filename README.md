# Machine Learning From Scratch 🚀

A collection of core machine learning algorithms implemented entirely from scratch using Python, NumPy, and Pandas. 

The goal of this repository is to move away from treating machine learning as a black-box library (`model.fit()`) and instead understand the underlying mathematics, optimization mechanics, and vectorization techniques.
